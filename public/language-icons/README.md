# Language icons

Selected original SVG icons from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), distributed under the included MIT license. Brand names and logos belong to their respective owners.

These assets are bundled locally; no CDN is used at runtime. Unsupported languages retain their text labels. Mappings are maintained in `src/editor/langHint.ts`.
